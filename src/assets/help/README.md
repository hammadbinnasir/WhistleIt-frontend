# Help media

Optional Help illustrations can be added here as GIF, SVG, PNG, JPG, JPEG, or WebP files.
Article images use the article's `id` from [helpContent.js](../../features/shell/help/helpContent.js)
as the filename, without an extension (for example, `features-2.gif`). Topic icons and carousel
slides use the media `name` defined in that same file (for example, `icon-features.svg`).

The Help UI uses its built-in artwork when no optional image is present. A media entry can also
provide an `image` or `url` instead of a local file.
